# 🏡 单词小镇 · WordFarm

给四年级学生的英语单词拼写游戏。**目标：一次游玩后，能根据中文意思独立拼写出 10 个以上的单词。**

## 怎么开始

```bash
cd word-game
# 方式一：直接打开
open index.html          # macOS

# 方式二：起个本地服务（更稳，speechSynthesis 在部分浏览器 file:// 下受限）
python3 -m http.server 8899
# 浏览器访问 http://127.0.0.1:8899/index.html
```

零依赖、纯前端、离线可玩。进度存在浏览器 `localStorage`（同一浏览器换设备不同步）。
支持手机/平板/电脑，`file://` 双击即玩。

## 玩法

| 界面 | 作用 |
|---|---|
| 📖 学单词 | 12 个单元（人教 PEP 四上/四下），选单元进入一关 |
| ⚔️ 试炼 | 12 词 Boss 挑战，三颗心，答错扣心，全对通关 |
| 🐣 小伙伴 | 宠物养成，按「牢记单词数」进化：蛋→幼宠→小宠→伙伴→大将 |
| 🏡 小镇 | 用星星买建筑、摆到小镇空地里 |

## 一关的四段流程（每次 3-4 分钟）

```
① 认识新朋友  看图 + 看拼写 + 跟读（建立编码）
② 我来写写看  只看中文意思，独立拼写 ← 核心检索
③ 交错练习    错词优先、顺序打乱（间隔化）
④ 闪电复习    全单元快过一遍（巩固）
```

12 个词 × 3 次检索 = **一次游玩至少 36 次主动拼写练习**，远超被动看词次数。

## 教学设计依据（研究结论 → 落地机制）

| 研究结论 | 游戏里的实现 |
|---|---|
| **检索练习**对 9-10 岁儿童效应量 d≈0.5-0.6，5 周后仍保持（Karpicke / Roediger & Karpicke，Frontiers in Psychology 2016；PLOS ONE 2013） | 全程「先遮答案尝试回忆」，不允许边看边拼。提交前格子为空 |
| **间隔重复**优于集中练习（艾宾浩斯遗忘曲线；Haebig et al. 2021 证实儿童 spaced retrieval 参数习得更快） | 关内四段交错 + 跨天 SRS 排程（10 分钟 / 1 天 / 3 天 / 7 天） |
| **即时反馈**让儿童学习更快（ASHA JSLHR 2025 关于 5-9 岁儿童的 retrieval practice 研究） | 每词即时判定，答错立刻显示正确拼写；第 4 级提示=直接给答案 |
| **多模态编码**（图 + 音 + 义 + 动手）记忆更深 | emoji 图形 + TTS 发音 + 字母块点击 + 键盘输入 + 音节拆分 + 谐音/词根钩子 |
| 游戏化设计本身是显著中介变量（Yu 2023 SAGE Open；Chiu et al. 2012 meta-analysis 显示 meaningful game > drill，效应量差异大） | 核心循环内建：检索 → 星星 → 建镇 → 宠物进化 → 解锁 Boss |
| **提示要克制**——成功的初次检索才能产生学习收益（Frontiers 2016 强调 "initial retrieval success"） | 四级渐变提示，越早自己写对收益越高：无提示 = 2 星，用提示 = 1 星 |

### 「牢记」的判定（不是答对一次就算）

需同时满足：复习间隔 ≥ 7 天、连续 3 次拼对、且 3 次都没看提示。
所以每关要连着练几天，这一设计是为了对抗「当时会、过两天忘」。

## 词库

人教 PEP 小学英语（三年级起点）四年级上/下册，共 12 单元 111 词。
选词剔除 `or`/`her`/`his` 等纯语法功能词（拼写检索无教学意义）。

每个词带 5 个字段：`w` 单词 / `zh` 中文 / `emo` 图形 / `syl` 音节拆分 / `tip` 记忆钩子。
自定义词表：直接编辑 `data/words.js`，在 `BOOKS` 里加单元即可，UI 自动生效。

## 已知边界

- TTS 用浏览器内置 `speechSynthesis`，音色随系统； macOS/iOS 是 Samantha，Android 是 Google TTS。若无声不阻塞游戏。
- `localStorage` 不同步，换设备进度清零；隐私模式下存档可能写入失败（已 try/catch 降级）。
- 物理键盘输入会与手机软键盘并存；键盘上的 3 个干扰字母是故意加来防瞎猜的。
